# 📊 Módulo: Stack SRE & Observabilidad

Aprovisionamiento de la suite de confiabilidad **SRE**:
- **Prometheus Operator:** Recolección de métricas de Kubernetes, nodos y aplicaciones.
- **Alertmanager:** Alertas basadas en el consumo de presupuesto de error (*Error Budget Burn Rate*).
- **Grafana:** Visualización de los *4 Golden Signals* (Latencia, Tráfico, Errores y Saturación).
